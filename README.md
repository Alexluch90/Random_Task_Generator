# Random Task Generator

**Author:** Квашнина Алина

## Description

Random Task Generator is a desktop application built with Python that helps users generate random tasks for different categories (Work, Sport, Study). The application features:

- Random task generation with configurable difficulty levels
- Custom task creation
- Task filtering by type and difficulty
- History tracking of generated tasks
- Persistent storage using JSON
- User-friendly GUI with Tkinter

## Features

- 🎲 **Random Task Generation**: Generate random tasks from predefined lists
- ➕ **Custom Tasks**: Add your own tasks with custom descriptions
- 🔍 **Filtering**: Filter tasks by type (Work/Sport/Study) and difficulty (Easy/Medium/Hard)
- 📜 **History**: Keep track of the last 100 generated tasks
- 💾 **Persistence**: All tasks are automatically saved to `data_f.json`
- 🎨 **Modern GUI**: Clean and intuitive interface built with Tkinter

## Requirements

- Python 3.7 or higher
- Tkinter (usually included with Python)
- No additional packages required
